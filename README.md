# RED NOVA — Mystery Box

Primera maqueta visual de RED NOVA.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño responsive azul/celeste con efectos visuales.
- `script.js`: interacciones de demostración.
- `assets/red-nova-logo.png`: logo enviado por la usuaria.

## Importante
Esta versión es solamente la interfaz visual. Todavía NO valida códigos reales, NO entrega premios reales y NO contiene autenticación ni panel administrativo funcional. Esas funciones se conectarán después a una base de datos Supabase independiente.
